
# Assets Directory

This folder contains static assets for the SML application.

## Recommended Structure

```
/src/assets
  /icons
    - favicon.ico
    - apple-touch-icon.png
    - logo.png
  /images
    - hero-bg.jpg
    - products/
```

## Usage
Import assets in `src/assets/index.ts` and export them via the `ASSETS` object.
